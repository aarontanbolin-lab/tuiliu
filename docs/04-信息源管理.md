## 九、综合评估

### 整体可获取性分布
```
🟢 无需账号，难度低（RSS/开放API）： 约 12 个信源
🟡 无需账号，难度中（需爬虫）：      约 18 个信源
🟠 需注册/API Key：                  约 8 个信源
🔴 收费/机构账号（暂不纳入首期）：   约 2 个信源
```

### 关于精准度的诚实说明

**可保证高精准度的信源：**
- 官方机构（国家统计局/央行/证监会/美联储等）：一手数据，100%可靠
- 结构化API（财联社/arXiv/FRED等）：机器可读，不产生人工转录错误
- RSS源：结构稳定，内容直接获取

**存在精准度风险的信源：**
- 网页爬虫：页面结构变更可能导致获取失败或内容错位
- 反爬措施：部分网站可能拦截自动化请求
- 全文字段提取：长文章中关键句提取可能有AI偏差

**风险应对策略（将纳入 `06-数据采集规范.md`）：**
1. 每个爬虫信源配异常检测，获取失败时标记而非静默跳过
2. 关键数据点交叉验证（如CPI从统计局+央行+东方财富三方验证）
3. 每日报告末尾标注各信源获取状态（成功/失败/降级）
4. 关键事实段落保留原文+来源链接，不自我总结
