# 推流 v2.0 需求文档

## 定位升级

从"数据采集+自动分类"升级为**编辑精选早报**。
对标：华尔街日报的编辑质量 + 中央内参的信息密度。
目标阅读时间：30分钟以内。

## 核心原则

1. 全中文环境——砍掉所有英文学术论文源
2. 编辑视角——不是"来什么展示什么"，而是"挑重要的、写导读"
3. 总条数控制在30-50条，条条有含金量
4. 排版精美，阅读体验舒适

## 信源重构

### 砍掉（6个英文学术源）
- Nature, Science, PNAS, arXiv, IEEE Spectrum, MIT Technology Review

### 保留（4个）
- 36氪、财联社、量子位、Federal Reserve（美联储公告，翻译摘要）

### 新增中文源
- 新华网财经 / 人民网财经
- 证券时报
- 第一财经
- 各部委公告RSS（国务院、发改委、工信部、央行等）
- 社会热点聚合

## 版块重构（6个）

| 版块ID | 名称 | 说明 |
|--------|------|------|
| top_story | 今日焦点 | 1-2条最重要的封面故事，编辑撰写导读 |
| policy | 政策风向 | 各部委最新公告、行业政策变动 |
| finance | 金融脉搏 | 利率汇率、市场资金面、统计数据 |
| industry | 产业前沿 | 行业动态、科技商业化进展 |
| global | 全球视野 | 国际重要事件精要（翻译提炼） |
| ipo | 准IPO/打新 | 过会动态、即将发行股票信息 |

## 编辑流程

采集 → 去重 → 编辑筛选（只留重要） → 撰写导读 → 分类 → 渲染

## 排版要求

- 封面故事大标题 + 编辑按语
- 版块导读段落（不直接扔文章列表）
- 标题层次分明、留白充足
- 色彩克制、字体优雅
- 移动端优先

## 打新信息

准IPO版块需包含：
- 近期过会企业
- 即将发行新股（申购日期、代码、发行价）
- 申购建议（可选）
