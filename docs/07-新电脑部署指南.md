# 推流 — 新电脑部署指南

> 适用场景：换电脑后，在新机器上重新部署完整的推流（Tuiliu）产品环境。
> 本指南配合"一键部署提示词"使用。

---

## 前置准备（在新电脑上完成）

### 1. 安装基础环境

- **Python 3.11+**：[python.org](https://www.python.org/downloads/) 下载安装，勾选"Add to PATH"
- **Git**：[git-scm.com](https://git-scm.com/download/win) 下载安装
- **WorkBuddy**：已登录你的 WorkBuddy 账号

### 2. 从旧电脑复制敏感配置文件

旧电脑路径：`C:\Users\m1923\Desktop\推流\config\settings.yaml`

> ⚠️ 此文件包含飞书 Webhook URL 和 API Key，已被 `.gitignore` 排除，不会随 Git 同步。
> **必须从旧电脑手动复制到新电脑的同路径。**

复制到新电脑后放置于：`{你的项目路径}\config\settings.yaml`

### 3. 配置 GitHub SSH/Token（用于推送）

```bash
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的GitHub邮箱"
```

推荐使用 GitHub CLI 或 Personal Access Token 认证。

## 常见问题

### Q: settings.yaml 丢了怎么办？
飞书 Webhook URL 可在飞书群机器人设置中重新获取，FRED API Key 可在 https://fred.stlouisfed.org/docs/api/api_key.html 重新申请（免费）。

### Q: GitHub push 报认证错误？
配置 Git 凭证：
```bash
# 方式一：GitHub CLI
gh auth login

# 方式二：Personal Access Token
git remote set-url origin https://{token}@github.com/aarontanbolin-lab/tuiliu.git
```

### Q: 虚拟环境路径不对？
新电脑的用户名可能不同（不是 m1923），将所有路径中的 `m1923` 替换为新用户名即可。
