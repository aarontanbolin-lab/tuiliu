## 一、设计原则

| 原则 | 说明 |
|------|------|
| **移动端优先** | 以手机竖屏为主要阅读场景设计，逐步适配宽屏 |
| **出版物品质** | 参考《财新》数字版、FT中文网的排版正统感 |
| **高密度不压迫** | 信息量大，但通过留白、分栏、字体层级保持呼吸感 |
| **不花哨** | 无动画、无弹窗、无广告；设计为目的服务，不为炫技 |
| **报纸基因** | 分栏布局、标题层级、首字下沉等传统报纸设计语言 |

## 二、视觉风格


## 四、关键设计元素

### 1. 信息源标记
每条资讯后标注来源，格式：`[来源：财联社 | 36氪]`
疑似重要信息但来源单一的内容加注：`⚠️ 单一信源，待交叉验证`

### 2. 原文引述块
对关键政策/数据内容，使用引述块保留原文：
```css
blockquote {
  border-left: 3px solid #C41E3A;
  padding-left: 16px;
  color: #1A1A1A;
  background: #F5F2ED;
  font-style: normal; /* 不用斜体，保持可读性 */
}
```

### 3. 数据可视化
- 使用 Chart.js（CDN引入）
- 移动端图表宽度100%，高度自适应
- 配色使用版块专属色系
- 所有图表标注数据来源和时间

### 4. 准IPO企业卡片
- 卡片式布局，白色底 + 浅阴影
- 内含：企业名称、拟上市板块、核心业务一句话
- 展开查看：商业模式、竞争优势、风险提示

### 5. 每日寓言排版
- 独立视觉风格，暖色背景
- 故事本体使用较大字号
- 概念揭示和隐喻解析使用折叠/区分样式

## 五、响应式断点

| 断点 | 设备 | 布局调整 |
|------|------|------|
| < 480px | 手机竖屏 | 单栏、全宽、精简字号 |
| 480-768px | 手机横屏/小平板 | 单栏、增加内边距 |
| 768-1024px | 平板 | 可双栏（正文+侧栏索引） |
| > 1024px | 桌面 | 正文居中（max-width: 800px）+ 右侧悬浮目录 |
| > 1440px | 大屏 | 正文居中 + 双栏信息展示 |

## 六、禁止事项
- ❌ 不使用emoji作为内容中的装饰（保持严肃感）
- ❌ 不使用自动播放的音频/视频
- ❌ 不设置弹窗/关注引导
- ❌ 不在报告内放置任何广告或推广内容
- ❌ 不使用过度的CSS动画
