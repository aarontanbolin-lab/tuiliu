# 推流 — 数据采集规范

> 版本：v1.0  
> 最后更新：2026-06-08  

---

## 一、采集原则

1. **诚实标注**：每条信息标注来源和获取时间
2. **不篡改原文**：关键事实以原文/结构化数据为准，AI仅做归类和关联
3. **交叉验证**：重要数据点（CPI、政策原文等）从多个信源交叉验证
4. **失败透明**：信源获取失败时在报告中标注，不静默跳过
5. **尊重robots.txt**：爬虫遵守网站的爬取协议

---

## 二、采集优先级

### 优先采集（高信噪比，必有）
1. 官方统计数据（国家统计局、央行、海关总署）
2. 政策原文（国务院、发改委、工信部、证监会）
3. 央行/Fed声明原文
4. arXiv 今日高关注度论文
5. 三大交易所公告

### 可选采集（有则更好）
1. 财经媒体快讯（财联社、36氪、华尔街见闻）
2. 科技媒体深度报道
3. 顶级期刊论文摘要
4. 期货交易所数据

### 降级采集（信源不稳定时）
各方向保留1-2个"永不故障"的兜底信源

---

## 三、去重规则

| 优先级 | 规则 |
|------|------|
| 1 | URL完全匹配 → 去重 |
| 2 | 标题相似度 > 85% → 去重，保留信息更完整的版本 |
| 3 | 同一事件不同信源 → 合并，标注多源 |

---

## 四、内容处理规则

### 政策类
- 必须保留政策原文全称和文号
- 必须标注发布日期和生效日期
- 摘要放在前面，原文关键段落紧跟其后

### 数据类
- 必须标注数据来源、统计口径、时间范围
- 环比/同比变化必须明确标注
- 图表数据与文字数据必须一致

### 科学类
- 必须标注论文标题、作者/机构、预印本编号（如有）
- 区分"已发表"和"预印本"
- 说明研究方法和主要发现，不夸大

### 准IPO类
- 过会日期、拟上市板块、保荐机构（基本事实）
- AI分析部分明确标注"AI分析"
- 风险提示为必填项

---

## 五、异常处理

| 情况 | 处理方式 |
|------|------|
| 单个信源超时（>30s） | 跳过，标记"超时" |
| 页面结构变更 | 跳过，标记"需更新爬虫" |
| HTTP 403/429 | 等待后重试1次，仍失败则标记"被限制" |
| 返回空数据 | 跳过，标记"无更新" |
| 数据格式异常 | 跳过，标记"格式异常"，记录样本 |

---

## 六、报告中的信源状态标注

每期报告末尾包含：

```
【今日信源状态】
✅ 正常：财联社、36氪、华尔街见闻、国家统计局、央行、arXiv...
⚠️ 降级：Nature（仅获取到摘要）
❌ 失败：生意社（超时）
📭 无更新：海关总署（今日无新数据发布）
```
