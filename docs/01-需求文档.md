## 一、产品定位

**推流** 是一款面向个人自用的高质量资讯富媒体研报产品。

### 核心理念
- **主动精选，拒绝被动投喂**：区别于短视频/自媒体/算法推荐的被动信息获取模式
- **内参级品质**：对标中南海领导人办公桌上的每日内参简报
- **AI为编辑，非作者**：AI负责结构化归类、关键摘录、上下文关联；关键事实保留原文，不得篡改
- **单一用户，深度定制**：你是唯一服务对象，所有内容围绕你的信息需求定制

### 产品名称含义
"推流" — 主动推送信息流，而非被动刷信息流。

## 二、信息版块（7大方向 + 1个创意版块）

### 1. 市场最热门行业
当前市场上受资本/政策/技术驱动最活跃的行业动态。

### 2. 供需关系变化（供小于求）
追踪关键商品/原材料/产业链环节供不应求的信号。

### 3. 前沿基础科学与技术突破
- 基础科学重大进展
- 前沿科学应用案例
- 技术工程化突破

### 4. 行业政策变动
影响具体产业的国家/部委政策。

### 5. 金融政策变动
央行/监管/国际金融政策调整。

### 6. 金融统计数据变动
关键经济/金融指标变化。

### 7. 准IPO企业追踪（子版块，归属金融资讯）
- 实时更新已过会但暂未上市的企业名单
- 每家企业包含：简介、核心商业模式、竞争优势、风险点等AI分析

### 8. 每日寓言（创意版块）
- 每日选一个研究生层级的概念（来自任意学科领域）
- 用一则寓言故事间接讲透这个概念
- 结构：故事 → 概念揭示 → 隐喻解析

## 三、内容要求

| 维度 | 要求 |
|------|------|
| 篇幅 | 深度长文级别，5000-10000字 |
| 信息密度 | 高密度，每篇有实质信息增量 |
| 信源可追溯 | 每条关键信息标明来源 |
| AI角色 | 提炼归类，关键信息不篡改原文 |
| 分类清晰 | 按版块分门别类，信息流完整 |

---

## 四、视觉与体验要求

| 维度 | 要求 |
|------|------|
| UI品质 | 精致、出版物级别排版 |
| 可读性 | 高可读性，排版舒适 |
| 移动端 | 移动端优先，响应式设计 |
| 桌面端 | 不可忽视，适配宽屏阅读 |
| 视觉风格 | 参考《财新》数字版、《纽约时报》数字版品质 |

---

## 五、推送要求

| 维度 | 要求 |
|------|------|
| 推送方式 | 飞书机器人推送每日URL |
| 推送时间 | 每日早上 8:00 |
| 承载形式 | 响应式HTML页面，CloudStudio部署 |
| 触达方式 | 飞书消息（摘要 + 完整报告链接） |
