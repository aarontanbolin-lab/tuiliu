## 开发原则

1. **小步快跑**：每个 Phase 包含 3-5 个可独立验证的小步骤
2. **遇阻即停**：每个步骤遇到问题 → 给出方案 → 用户确认 → 继续
3. **文档先行**：开发过程中对照 `docs/` 下标准化文件执行
4. **日志同步**：每完成一个步骤，更新 `开发日志/TODO.md` 和当日日志
5. **不跳步**：Phase N 完成并验证后，才启动 Phase N+1
